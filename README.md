# For Sakshi 💗 — apology website

A small, mobile-friendly, single-page apology website. It uses plain HTML, CSS and JavaScript, so it needs no build tools, dependencies, or backend.

## Preview locally
1. Extract the ZIP.
2. Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create a new **public** GitHub repository (for example, `for-sakshi`).
2. Upload `index.html` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then click **Save**.
6. Wait a minute or two. GitHub will show the published URL, usually:
   `https://YOUR-USERNAME.github.io/for-sakshi/`

Send Sakshi that published URL.

## Personalize before publishing
Open `index.html` in VS Code and edit the letter inside `<article class="letter" id="letter">`.
The copy is intentionally warm and best-friend focused. Change any line that doesn't sound like you.

## Notes
- No external fonts, images, libraries, trackers, or API calls.
- Works on phones and desktops.
- The envelope opens the letter; the **FORGIVEN!** button triggers a celebratory heart animation.
